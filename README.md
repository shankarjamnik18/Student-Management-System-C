# Student Management System | C Programming

## Project Overview

The Student Management System is a menu-driven application developed using the C programming language.

It is designed to manage student records efficiently and provides different operations such as adding, displaying, searching, updating, deleting, sorting, and storing student information.

## Features

- Add student records
- Display all students
- Search students by first name
- Search students by CGPA
- Update student details
- Delete student records
- Sort students by Roll Number
- Sort students by CGPA
- Save student records to a file
- Load student records from a file
- Count total number of students
